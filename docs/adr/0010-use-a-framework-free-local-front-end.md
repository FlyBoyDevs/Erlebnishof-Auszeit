# Use a framework-free local front end

The public site will remove Bootstrap CSS, Bootstrap JavaScript, Bootstrap Icons, and their jsDelivr requests. Layout and presentation will use consolidated local CSS; interactions will use small local JavaScript modules; icons will be local SVG assets. The replacement Bilderkarussell is an explicitly tested component supporting touch swipe, arrows, position indicators, keyboard operation, correct focus handling, and fullscreen viewing. Content carousels do not autoplay; only the Hero-Bildfolge may rotate automatically under the shared Bewegungspräferenz.
