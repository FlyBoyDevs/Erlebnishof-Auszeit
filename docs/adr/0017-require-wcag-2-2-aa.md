# Require WCAG 2.2 level AA

The public site and Redaktionsbereich use WCAG 2.2 level AA as an internal release criterion, not a public certification claim. Verification combines automated analysis with manual keyboard, visible-focus, contrast, meaningful-alt-text, 200–400% zoom and reflow, screen-reader, touch-target, reduced-motion, Bilderkarussell, and fullscreen-dialog tests. A passing Lighthouse score alone is not sufficient, and the editorial interface must help Bearbeitungsberechtigte preserve accessible headings, link text, image descriptions, and readable content.
