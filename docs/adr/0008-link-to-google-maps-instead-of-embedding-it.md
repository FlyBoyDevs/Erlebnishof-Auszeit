# Link to Google Maps instead of embedding it

The site will show its address, directions context, and explicit links for route planning and the current menu without embedding Google Maps. No Google Maps resource is loaded until a guest chooses one of those links. This keeps the initial page faster, avoids disclosing visitor data to Google on page load, and still supports the external service guests already use frequently.
