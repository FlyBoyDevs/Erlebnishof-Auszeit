# Hofladen

Simple website project that runs on Apache with PHP for the admin area.

## Start with Apache + PHP

1. Install Apache and PHP 8.x on your machine.
2. Make sure Apache has PHP enabled.
3. Set the project root (`/Users/kyle/projects/hofladen`) as the Apache `DocumentRoot`.
4. Restart Apache.
5. Open the site in your browser at `http://localhost/`.
6. Open the admin area at `http://localhost/admin/`.

## Notes

- The main site is served from the repository root.
- The `admin/` folder contains the PHP-based admin interface.
