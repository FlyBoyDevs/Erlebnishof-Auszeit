# Limit the admin area to current information

The authenticated PHP Redaktionsbereich will manage only Aktuelles & Termine, Abweichende Öffnungszeiten, Spring/Summer/Autumn Themenfenster, and the Themenmodus. Main copy, galleries, regular opening hours, contact details, and legal pages remain repository-managed and require a reviewed code release even when a correction is urgent. This keeps owner-operated updates convenient without introducing the security, validation, preview, versioning, and maintenance scope of a general-purpose CMS.
