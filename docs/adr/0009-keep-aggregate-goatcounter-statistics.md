# Keep aggregate GoatCounter visitor statistics

The site will retain its hosted GoatCounter integration because the owner actively uses the statistics, subject to verification of the real hosted configuration and Rechtliche Freigabe. The intended mode is aggregate collection without individual pageview storage or browser-side identifiers. GoatCounter loads only on the production hostname; its network data, operator relationship, retention, and legal basis are documented accurately. If verification or legal review does not support the intended no-consent operation, GoatCounter is disabled before launch and this decision is revisited.
