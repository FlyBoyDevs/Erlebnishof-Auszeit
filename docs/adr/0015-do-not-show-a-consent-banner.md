# Do not show a consent banner

The site will not display a consent or cookie banner if the verified production implementation and Rechtliche Freigabe support doing without one. The intended design uses local assets, click-only external links, and GoatCounter only under ADR 0009. A Bewegungspräferenz is remembered only after the guest changes it; a generation/sequence read version is remembered only after **„Aktuelles auf diesem Gerät als gelesen markieren“**, with a reset action. The dot is computed only from currently visible entries newer than that read version, so expired content cannot leave an absent notification. Datenschutz describes the real hosting, analytics, both preferences, and outbound links. Any new non-essential device storage, automatic third-party embed, or materially different analytics configuration requires a fresh legal and architectural decision before deployment.
