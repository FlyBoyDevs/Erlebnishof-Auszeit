# Model Hofcafé and Hofladen as linked business components

The visible venue remains Erlebnishof Auszeit. Its single LocalBusiness JSON-LD object uses Google’s supported **department** relationship to nest two stable-ID components at the same verified address: **Erlebnishof Auszeit Hofcafé** as **CafeOrCoffeeShop** and **Erlebnishof Auszeit Hofladen** as **Store**. Each department has its own regular hours and applicable exceptions matching the visible page. A single component with both types is rejected because it cannot associate the materially different schedules correctly; successful validation does not guarantee that Google will display an enhancement.
